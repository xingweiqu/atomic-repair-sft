# PREREG_bendpoint — 可教前沿弯点 + G/B 赛跑协议(C-12 B2;训练前冻结,2026-07-12)

> Tier 2 已证 ≤3 步显式规则完全可教(NOTES_tier2_frontier,CL-2);前沿在 3 步内没弯。
> 本实验定位弯点 + 把"可教"升级为赛跑判据。CL-2 措辞待此实验后升级。

## 1. 新档位(沿 Tier 2 构造:发明运算,构造性零泄漏,token 审计 p95≤129 口径放宽至 p95≤160)

| 档 | 规则 | 拆什么 |
|---|---|---|
| e | 五步规则(链式,无分支) | 纯深度 |
| f | 条件分支(if a>b then 路径1 else 路径2,每路径 ≤2 步) | 控制流 |
| g | 自然语言包装的 b 档一步规则(题面故事化,规则不显式给出) | 包装 vs 深度混杂 |

各档 train 2000 / eval 1000;OOD 切分照 Tier 2 冻结口径
(未见组合 [0,99] = ID;三位数 [100,999] = OOD,A 判据用 OOD)。

## 2. G/B 赛跑协议(测量单位 = 单次训练内的 epoch 轨迹)

单 run 16 epochs,**每 epoch 存 ckpt**(与山脊协议的"独立 run 每档 epoch"不同:
赛跑问的是"同一次训练内谁先到",LR 调度按 16 epoch cosine 一次成型;
与既有脊点协议的差异如实披露,两者不混引)。
逐 epoch 记:eval-ID acc / eval-OOD acc / json_bleed / mute(transfer300 素题)。

- **G(顿悟)= OOD 首次 ≥90% 的 epoch**;
- **B(中毒)= json_bleed 首次 >5% 的 epoch**(mute>12% 同为 B,取先到者);
- **可教判据 = G < B**;G 不存在(16 epoch 内 OOD 从未 ≥90%)记 G=∞。

## 3. 预测(冻结)

- **P-BP-e**:e 可教(G<B;OOD 终值 ≥85%)——深度 5 仍在前沿内侧。
- **P-BP-f**:f 是弯点候选——OOD 终值 <50% 或 G>B(两读法都算 HIT;
  f 若也全可教则"弯点不在控制流",继续外推,如实记)。
- **P-BP-g**:g 相对 b 档(99.6%)掉档 ≥20pp → **包装即成本**:GSM 不可修性的
  来源候选定位到"自然语言→计算的映射"(Tier 2 一句话读法的三候选之一);
  g 不掉档则该候选出局。
- 附带:a′ 毒校准床迁移(Tier 2 提案:校准床应在只有背过才能答对的档;
  本批在 e 档加 poison10 一臂,预测 Δ_ID ≈ +10×(1−acc_clean))。
