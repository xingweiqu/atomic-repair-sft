# PREREG_profile — 七探针 + 诊断画像(2026-07-11,本 commit 即时间戳;C-11 Loop 1/2)

## 1. 设计与度量冻结(R-23)
- 题池:GSM8K test(缓存 1300)+ GSM-hard 难桶(合并池 pass@8≤25%,569 题)= 1869 题。
- 七探针+O:O 原题 / P 语义不变改写 / S 给分解步骤表达式不给结果 / R 给通用规则不代数字 /
  C 给一个正确中间值 / W1 植入错误中间值 / W2 植入错误终断言 / F 同内容改输出格式(JSON)。
- 判分:素题 marker 精确匹配(F 型按其格式提取);pre-repair 模型,greedy,/no_think,2048。
- 逐题行为签名 = 8 位向量(每探针 对/错)。

## 2. 分类规则(C-11 Loop 2 原文,冻结)
scaffold 缺口=¬O∧S;规则缺口=¬O∧R∧¬S;表述脆弱=O 与 P 不一致;conduct 缺口=O∧¬W;
局部执行缺口=¬O∧¬S∧¬R∧C;组合缺口=局部步骤单问全对而整题错;format=仅 F 变动;
**Unresolved=全探针不救(诚实类,禁止硬塞)**。
steering 分诊列:conduct 疑似题推 d_plain@α8 重测,可 steer 率入 profile 表。

## 3. 闸门(先于 profile 管线)
- S/R/C **零答案泄漏 validator**(程序化:步骤结果值/最终答案不得出现在探针文本,
  题面自带数字豁免);P 语义等价 validator(数字集不变+长度比窗);W type-match 沿既有。
- **构念审计**:每型抽 100 条人工审计,通过率 ≥70% 准入;不达标整型降级探索性(Paper 1 Abl 教训)。
- 审计在画像**分类**之前;推理数据可先行收集(闸门守分类不守推理)。

## 4. 冻结预测
- O 基线:gsm test ≈94%(greedy 历史),难桶 ≈0-25%;
- prevalence 不预测具体数字(画像本身是测量,不是假设检验)——但预测**结构**:
  难桶内 Unresolved+局部执行 占多数;conduct 缺口在全池非空(W1/W2 存在 O∧¬W 题);
  format-only 差动 ≤5%(F 伪差受控)。
- 灰区形态:签名不满足任何规则组合的题 → 入 "mixed" 显式桶,不并入 Unresolved。
- 仪器故障态:P/R 生成质量崩(构念审计 <70%)→ 该型降级;提取 regex 对 F 型失配 → F 按其格式单独提取器。
- 七类伪影勾选:F判定(双提取器,受控)/F_floor(无训练,N/A)/M(无训练,N/A)/出血(pre-repair 无,N/A)
  /mute(报作答率)/仪器截断(2048+尾部检查)/叙事命名(分类名沿 C-11 术语,禁新造)。
- 合法结局:某型探针大面积无效(如 R 构念不达标)→ 画像降维如实报,不补造。
