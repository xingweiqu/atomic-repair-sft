# 设计卡模板 v2(C-18 迁移;每个数据集/评测集/训练臂一张,注册前必填)

- **名称 / 五轴落位**(逐格列出覆盖的 cell)
- **构念**(construct):这份数据声称测量/教授什么(一句)
- **注入面清单**:训练它可能顺带安装什么(体裁/服从/拒答倾向/接口偏置)——
  逐项列 + 对应监控列(retention 全家桶哪几列盯它)
- **构造规格**:底题来源/变体规则/validator 清单/think-lint/泄漏断言
- **构念审计**:样本 100 条路径 + 通过率 + 审计人;<70% = 该格缺格不硬造
- **判分**:ScoringTarget + 判分器文件 + strict/lenient 声明
- **单 seed 状态**:seeds 列表;单 seed 产物入图必空心
- **负结果价签**:若此臂/格产出负结果,验尸责任人写谁(默认 CC)
