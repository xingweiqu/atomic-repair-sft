## 形态(只报数,判定归 Xingwei/顾问)

1. **修复臂在修复腔里与安慰剂分离了**(A1/B/D 的 Δ = +10~16pp),
   而同样这批 ckpt 在素题 conduct 桶 Δ 只有 +2~7pp——
   "含修复组分是否有用"这件事的可见度**随体裁翻转**,方向符合 E1b 预言。
2. **但分开的仍不是"匹配的配比"**:B(均匀).735 > D(反转).702 > A1(画像).676,
   顺序与画像匹配度无关;B−A1=5.9pp,同臂跨 seed 散布 ±2.5~4pp,如实并报。
   即:修复腔放大的是"修复组分总量/多样性"的效应,不是"按桶对症"的效应。
3. **retrieve_or_abstain 是分离最狠的策略**:安慰剂 .063 / C .004 → A1 .217 /
   B .338 / D .438。"该弃答时弃答"没有免费地板,必须喂修复类数据——
   与素题 format 桶(核心 1%,无免费核心)同型。
4. **drills 在修复腔同样灾难**:overall .217(比 base 还低 11.6pp),
   false_keep 11.7%(全场最高)——"服从类数据"的危害跨体裁成立,
   反向疫苗判读再添一票(P-L5-drills 的行为学面)。
5. single_scaffold 修复腔 −11.9pp(素题里它救 format 94%)——
   组分的收益/危害本身也是体裁函数。
